# PI-CAI 1500 HPC Scripts

This folder now contains only the SLURM jobs for the current PI-CAI 1500
experiment. Older PI-CAI 1295 and intermediate fair-comparison jobs were moved
to `archive/scripts/hpc/`.

## Standard Order

Submit the complete current workflow from the repository root:

```bash
./run.sh
```

That submits the following jobs with `afterok` dependencies:

1. `10_picai1500_radiomics_ml.sh`
2. `11_picai1500_radiomics_dl.sh`
3. `12_picai1500_clinical_prep.sh`
4. `13_picai1500_clinical_ml.sh`
5. `14_picai1500_clinical_dl.sh`
6. `15_picai1500_reports.sh`

To inspect the order without submitting:

```bash
./run.sh list
```

## Optional Jobs

- `16_picai1500_reports_resume_dual.sh`: resume dual-branch interpretability and
  rebuild the publication report.
- `17_picai1500_dual_transformer_longtrain.sh`: train the longer dual
  Transformer variant and compare it with the baseline dual Transformer.
- `18_picai1500_total_energy_overlay.sh`: render one TotalEnergy voxel overlay.
- `34_picai1500_pirads_prepare.sh`: validate the July 2026 official PI-CAI
  marksheet, merge lesion-level PI-RADS into the 1500-case cohort as the
  maximum score per examination, and record annotation provenance.
- `35_picai1500_pirads_benchmark.sh`: compute patient-clustered PI-RADS
  performance, paired OOF comparisons against prespecified RF/TabFM models,
  histology-restricted sensitivity analyses, PI-RADS strata, and discordances.
- `36_picai1500_pirads_inputs.sh`: create aligned PI-RADS-only,
  PI-RADS+PSAD, radiomics+PI-RADS, and full combined tables plus locked
  five-fold feature plans for limited retraining.
- `37_picai1500_pirads_rf.sh`: run the four prespecified limited-retraining
  Random Forest experiments with nested tuning and the original five folds.
- `38_picai1500_pirads_tabfm.sh`: run the same four predictor sets with
  pretrained TabFM as the prespecified secondary analysis.
- `39_picai1500_pirads_compare.sh`: compare the RF and TabFM predictor sets
  overall, by center, and in the histology-confirmed sensitivity cohort using
  paired patient-cluster bootstrap.
- `40_picai1500_pirads_loco_rf.sh`: refit the two combined PI-RADS Random
  Forest models with leave-one-center-out folds and outer-training feature
  selection.
- `41_picai1500_pirads_loco_tabfm.sh`: run the two combined PI-RADS TabFM
  models with the LOCO feature plans generated by job 40.

## Environment Overrides

All jobs accept:

- `REPO_DIR`
- `PYTHON_MODULE`
- `VENV_ACTIVATE`

Report jobs also accept:

- `RUN_INTERPRETABILITY=0` to rebuild metrics/reports without rerunning native
  interpretability.
- `MAX_NATIVE_SAMPLES` and `IG_STEPS` for dual-branch resume jobs.

The current experiment writes under `results/radiomics/picai1500_corr/`, which
is ignored by Git.

### PI-RADS specificity at matched sensitivity

Jobs `42`–`44` estimate RF and TabFM operating points at the observed sensitivities of PI-RADS ≥3 and ≥4. Thresholds are selected only inside each outer-training fold; job `44` performs paired patient-cluster bootstrap comparisons of specificity.

```bash
rf_job=$(sbatch --parsable scripts/hpc/42_picai1500_pirads_equal_sensitivity_rf.sh)
tabfm_job=$(sbatch --parsable --dependency="afterok:${rf_job}" scripts/hpc/43_picai1500_pirads_equal_sensitivity_tabfm.sh)
sbatch --dependency="afterok:${tabfm_job}" scripts/hpc/44_picai1500_pirads_equal_sensitivity_compare.sh
```

## Second-round revision (EURE-D-26-00683)

Submit everything with dependencies from the repository root:

```bash
./run_revision2_experiments.sh
```

- `45_revision2_prepare_inputs.sh`: PI-RADS + clinical table and plans (five-fold
  and LOCO), corrected LOCO plans (manuscript selection settings with PI-RADS and
  clinical predictors forced), no-pre-filter and volume-excluded plans,
  per-fold feature counts, volume correlations, and Figure 6 extra cases.
- `46_revision2_classical_5fold.sh`: RF and penalized LR for PI-RADS + clinical,
  LR for the complete model, and their PI-RADS-derived sensitivity targets.
- `47_revision2_classical_loco.sh`: RF and LR LOCO for PI-RADS + clinical,
  radiomics + PI-RADS, and the complete model on the corrected plans.
- `48_revision2_feature_sensitivity_ml.sh`: complete model without univariable
  pre-filter (RF, elastic-net LR, LASSO LR) and with volume-correlated features removed (RF).
- `49_revision2_nested_selection_rf.sh`: radiomic selection refitted inside every
  inner split (nested) versus the locked outer-training selection.
- `50_revision2_tabfm_gpu.sh`: all corresponding TabFM runs.
- `51_revision2_voxel_lesion_quant.sh` (array) and `52_..._aggregate.sh`:
  voxel-map values inside versus outside the lesion in histology-confirmed csPCa.
- `53_revision2_analyses.sh`: paired contrasts, LOCO per-center discrimination and
  calibration, decision curves, partial AUROC, 2x2 tables, sensitivity analyses.
- `54_revision2_tabfm_shap.sh`: SHAP of the complete TabFM model with the pinned
  TabFM source and checkpoint used by job 50.

Outputs are written under `results/revision2_experiments/`.
